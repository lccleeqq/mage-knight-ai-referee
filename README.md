# Mage Knight AI Referee

Phase 1 prototype: a rules referee that checks whether a described action conflicts with the currently loaded demonstration rules. It does not recommend strategies.

## GitHub Pages

The repository contains a GitHub Actions workflow that deploys the static app to GitHub Pages whenever `main` changes.

After enabling Pages with **GitHub Actions** as the source, the site will be available at:

`https://lccleeqq.github.io/mage-knight-ai-referee/`

## Important

This is a prototype. The current rule set is deliberately small. Before using it as an authoritative referee, the rule database should be built from the exact Mage Knight edition/rules documents and checked against official errata/FAQ.
